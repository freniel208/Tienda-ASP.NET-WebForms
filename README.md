# 🛒 Sistema de Gestión de Tienda (ASP.NET Web Forms)

Proyecto web desarrollado en C# bajo una arquitectura de 3 capas, integrado con SQL Server para el almacenamiento de datos y diseñado con una interfaz moderna basada en Bootstrap 5.

## 🚀 Tecnologías Utilizadas
* **Lenguaje:** C# (.NET Framework)
* **Framework Web:** ASP.NET Web Forms
* **Diseño UI:** Bootstrap 5 (CDN)
* **Base de Datos:** SQL Server (Procedimientos Almacenados / Stored Procedures)
* **Arquitectura:** 3 Capas (`Entidades`, `CapaDatos`, `CapaNegocio`)

## 📌 Funcionalidades
* **Mantenimiento de Categorías:** CRUD completo (Listar, Agregar, Editar, Eliminar).
* **Mantenimiento de Productos:** CRUD completo enlazado relacionalmente con las categorías existentes.
* **Validaciones:** Control de campos obligatorios mediante `RequiredFieldValidator`.
* **Diseño Responsivo:** Adaptado a pantallas móviles y de escritorio mediante tarjetas y cuadrículas estilizadas.
